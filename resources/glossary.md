# Glossary

Terminology used throughout the guide, with definitions that aim to be accurate without being intimidating. Drawn from across all chapters and consolidated alphabetically.

---

### APC (Article Processing Charge)
A fee charged by some journals to publish an article open access. Ranges from a few hundred dollars to over $11,000 depending on journal and publisher. *(Ch.6)*

### Apparatus
Hardware or software acting as an instrument in research. One of the four material categories defined in Chapter 8. *(Ch.8)*

### ARRIVE
Animal Research: Reporting of *In Vivo* Experiments. A reporting guideline for animal studies. *(Ch.5)*

### Branch
In Git, a parallel line of work that can be merged back into the main line later. Lets you experiment without breaking what already works. *(Ch.7)*

### CARE Principles
Collective benefit, Authority to control, Responsibility, Ethics. Complement FAIR for materials involving indigenous and community data. Defined in Carroll et al 2020 (*Data Science Journal*). *(Ch.8)*

### CC BY 4.0
Creative Commons Attribution 4.0 International License. The most common open license for scholarly prose. Allows reuse and adaptation with attribution. *(Ch.6)*

### CHAT
Codes for the Human Analysis of Transcripts. Transcription standard used by CHILDES and TalkBank archives. Documented in MacWhinney's *The CHILDES Project* (2000). *(Ch.8)*

### CITATION.cff
A machine-readable citation file format. Drop one at the top of a GitHub repo and a "Cite this repository" button appears on the repo's landing page. *(Ch.7)*

### Clone
A complete local copy of a remote Git repository. *(Ch.7)*

### Codespaces
GitHub's cloud development environment - a full Linux machine and editor in your browser tab, pre-configured with whatever the repo needs. *(Ch.7)*

### Commit
A labeled snapshot of changes in a Git repository, with a timestamp, author, and message. *(Ch.7)*

### CONSORT
Consolidated Standards of Reporting Trials. A reporting guideline for randomized controlled trials. *(Ch.5)*

### Consortium (collaborative-protocol)
A multi-institution collaborative running a shared protocol across sites. Examples: Many Labs, ManyBabies, Psychological Science Accelerator, Open Reaction Database, ManyPrimates. *(Ch.8)*

### Container
A lightweight isolated runtime environment that bundles software and its dependencies. Docker is the most common implementation. *(Ch.4)*

### Copilot
GitHub's AI assistant. Available as Chat (ask questions about a repo), Coding Agent (assigned to issues), and editor integration. *(Ch.7)*

### COREQ
Consolidated Criteria for Reporting Qualitative Research. A reporting guideline for interviews and focus groups. *(Ch.5)*

### Crossref
DOI registration agency for journal articles. *(Ch.6)*

### DataCite
A registry for assigning DOIs to datasets and other research outputs. *(Ch.3, Ch.6)*

### Diamond OA
An open-access publishing model with no article processing charges to authors and no subscription fees to readers. Funded by institutions, societies, or grants. *(Ch.6)*

### Diff
A side-by-side comparison of two versions of a file. *(Ch.7)*

### DMP (Data Management Plan)
A document describing how research data will be collected, stored, shared, and preserved. Increasingly required by funders. *(Ch.3)*

### DOAJ
Directory of Open Access Journals. A curated list of legitimate open-access journals, useful for avoiding predatory publishers. *(Ch.6)*

### DOI
Digital Object Identifier. A permanent, citable identifier for a scholarly object. *(Ch.3, Ch.6)*

### ELAN
Multimedia annotation tool from the Max Planck Institute. Paired with the EAF file format for time-aligned annotation. *(Ch.8)*

### EQUATOR Network
The master catalog of reporting guidelines across health research. *(Ch.5)*

### FAIR
Findable, Accessible, Interoperable, Reusable. The guiding principles for good data stewardship, defined in 2016. *(Ch.3)*

### Fork
A personal copy of a Git repository, used as a starting point for changes you might propose back via a pull request. *(Ch.7)*

### Git
A distributed version-control system. The underlying technology behind GitHub, GitLab, and Bitbucket. *(Ch.7)*

### GitHub
A web platform for hosting Git repositories and adding collaboration features (issues, pull requests, code review, websites, AI tools). *(Ch.7)*

### GitHub Actions
GitHub's built-in continuous-integration system. Runs scripts automatically when events happen in a repo (push, PR, schedule). *(Ch.4, Ch.7)*

### GitHub Pages
Free static-site hosting from a GitHub repo. *(Ch.7)*

### Gold OA
An open-access publishing model where the version-of-record is freely available immediately upon publication, typically funded by APCs. *(Ch.6)*

### Green OA
Self-archiving. Depositing a version of an article (preprint or accepted manuscript) in a repository, often with an embargo period. *(Ch.6)*

### Hybrid OA
A subscription journal that offers per-article open access in exchange for an APC. *(Ch.6)*

### IRB (Institutional Review Board)
University board overseeing research with human subjects. *(Ch.2, Ch.3)*

### Issue
A numbered, threaded discussion thread attached to a GitHub repository. Used for tasks, bugs, decisions, and questions. *(Ch.7)*

### Jupyter
Open-source interactive notebooks for Python, R, Julia, and other languages. *(Ch.4)*

### Linguistic documentation
The recording, annotation, and archival preservation of language data from a speech community. *(Ch.8)*

### Literate Programming
A programming style that interleaves narrative prose with code and output, designed for human reading. R Markdown, Quarto, and Jupyter are literate-programming tools. *(Ch.4)*

### Markdown
A lightweight plain-text formatting syntax (`**bold**`, `# heading`, `- list`) that GitHub renders into nicely formatted prose. *(Ch.7)*

### Material Transfer Agreement (MTA)
Contract governing transfer of physical research materials (plasmids, cell lines, reagents, samples, hardware) between institutions. *(Ch.8)*

### MDPI
A large publisher of open-access journals. Sometimes flagged for predatory practices around its Special Issues model; some MDPI journals are reputable, others are not. *(Ch.6)*

### Merge / Merge Conflict
Combining changes from one branch into another. A conflict happens when two branches edit the same lines of the same file. *(Ch.7)*

### OER (Open Educational Resources)
Teaching, learning, and research materials in any medium released under an open license. Hosted on OER Commons, MERLOT, OASIS, and institutional repositories. *(Ch.8)*

### ORCID
Persistent author identifier. Required by most major journals and funders. *(Ch.3, Ch.6)*

### OSF (Open Science Framework)
Free platform from the Center for Open Science for project management, pre-registration, and data sharing. *(Ch.1, Ch.2, Ch.3)*

### OSTP Memo (2025)
A White House Office of Science and Technology Policy memo requiring immediate public access to federally funded research, with no embargo. *(Ch.6)*

### Pre-registration
Publicly committing to a study's hypotheses and analytic plan before data collection (or before looking at the data). *(Ch.2)*

### Preprint
A version of a manuscript shared publicly before peer review, typically on a preprint server (arXiv, bioRxiv, medRxiv, ChemRxiv, OSF Preprints, PsyArXiv, etc.). *(Ch.6)*

### PRISMA
Preferred Reporting Items for Systematic reviews and Meta-Analyses. A reporting guideline for systematic reviews. *(Ch.5)*

### Pull Request (PR)
A proposal to merge changes from one Git branch into another, with a built-in space for discussion and review. *(Ch.7)*

### Quarto
An open-source scientific publishing system supporting R, Python, Julia, and Observable JS. Successor to R Markdown. *(Ch.4)*

### README
A file at the top of a repository that describes what the project is and how to use it. *(Ch.7)*

### Registered Report
A peer-reviewed format where the introduction and methods are reviewed before data collection; in-principle acceptance is granted on the basis of the planned design. *(Ch.2)*

### Release
A named, frozen version of a Git repository (e.g., `v1.0`). Releases can be archived to Zenodo for a permanent DOI. *(Ch.7)*

### Repository (repo)
A project's files plus its complete version history, hosted by Git. *(Ch.7)*

### Reproducibility
The ability of another researcher (or your future self) to obtain the same results from the same data and code. Distinct from replicability, which is obtaining similar results from new data. *(Ch.1, Ch.4)*

### Restricted-use archive
A repository where deposit is open but access requires a data-use agreement (e.g., ICPSR's restricted-use track). Used for IRB-sensitive social-science materials. *(Ch.8)*

### SHERPA RoMEO
A database of publisher self-archiving policies, useful for figuring out where you can post a preprint or postprint. *(Ch.6)*

### SRQR
Standards for Reporting Qualitative Research. A reporting guideline for qualitative studies. *(Ch.5)*

### Stimulus protocol
A document describing stimulus selection, identifiers, and norming sufficiently for others to assemble an equivalent set. Used when copyright blocks redistribution of the original stimuli. *(Ch.8)*

### STROBE
Strengthening the Reporting of Observational Studies in Epidemiology. A reporting guideline for observational studies. *(Ch.5)*

### Tiered access
Archive model where some materials are openly available and others are restricted by community agreement or IRB. ELAR, AILLA, and similar linguistic archives use this model. *(Ch.8)*

### TOP Guidelines
Transparency and Openness Promotion Guidelines. A tiered framework for journals adopting open-science practices. *(Ch.1, Ch.5)*

### Tromso Recommendations
A set of recommendations on data and materials citation in linguistics, articulated in Berez-Kroeker et al (2018, *Linguistics* 56(1)). Calls for citing data deposits as primary scholarly outputs. *(Ch.8)*

### UBMTA
Uniform Biological Material Transfer Agreement. Standardized template used by many US institutions for pre-approved biological-material transfers. *(Ch.8)*

### Version Control
A system that records changes to files over time so that you can recall specific versions later. Git is the dominant tool. *(Ch.7)*

### Zenodo
A general-purpose research repository operated by CERN, providing free DOIs for any kind of scholarly output (data, code, slides, posters, theses). *(Ch.3, Ch.6, Ch.7)*

### Zotero
An open-source reference manager with strong support for scholarly metadata and citation export. *(Ch.7)*
