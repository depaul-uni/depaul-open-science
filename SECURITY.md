# Security and Privacy

This repository contains an open educational resource (a guide). It is not a software product, and we do not anticipate security vulnerabilities in the conventional sense.

If you discover that the guide contains:

- **Personal data** about an individual (other than public author/contact information for SLC members)
- **IRB-restricted material** that should not be public
- **Copyright violations** (e.g., a verbatim chapter from a copyrighted source)
- **Privacy issues** of any kind

Please do not open a public issue. Instead, contact the SLC facilitator directly:

- **Vahid Alizadeh**: valizade@depaul.edu

We will review and respond within five business days.
